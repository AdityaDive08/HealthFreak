# 🌟 **Project Description – HealthFreak: AI-Powered Medical Voice Agent with Smart Health Tracking**

**HealthFreak** is an advanced AI-driven healthcare platform designed to provide personalized medical guidance through real-time voice interaction and continuous wearable health tracking. The system integrates **speech recognition, conversational AI, and biometric monitoring** into a unified, intelligent, and accessible digital health companion.

Unlike traditional fitness trackers or standalone medical chatbots, HealthFreak bridges the gap between **subjective user input** (voice symptoms) and **objective physiological data** (heart rate, sleep, steps, stress). This enables more accurate, context-aware insights and makes everyday health management simpler, proactive, and user-friendly.

---

## 🔹 **Core Idea**

To create a **voice-first healthcare assistant** that understands natural speech, analyzes real-time health metrics from wearables like Google Fit, offers medically guided responses, and triggers emergency alerts when abnormal patterns are detected.

---

## 🔹 **Key Components**

### **1. Real-Time Voice Interaction**

* Users talk naturally using voice commands.
* Speech is converted to text using **AssemblyAI**.
* Ideal for elderly users, visually impaired individuals, and those who prefer hands-free interaction.

### **2. AI-Based Medical Reasoning**

* User queries + wearable data are processed by **Google Gemini AI**.
* The system provides:

  * Symptom assessment
  * Preventive advice
  * Lifestyle recommendations
  * Safety-filtered medical guidance
* Ensures contextual awareness rather than generic chatbot responses.

### **3. Wearable Health Tracking**

* Continuous synchronization with **Google Fit** for:

  * Heart rate
  * Sleep duration
  * Stress levels
  * Steps & activity logs
* Data is used to improve AI accuracy and enhance personalized advice.

### **4. Emergency (SOS) Detection**

* Automatically detects abnormal metrics (e.g., high heart rate).
* Triggers alerts to emergency contacts or nearby hospitals using geolocation.
* Adds real-world safety and reliability to the system.

### **5. Interactive Web Dashboard**

* Built using **Next.js** and **Tailwind CSS**.
* Displays charts, health trends, and summaries.
* Allows users to review insights, symptoms, and AI suggestions visually.

### **6. Secure Backend & Data Privacy**

* **Node.js + Express** backend with Drizzle ORM and NeonDB.
* Authentication handled by **Clerk**.
* Ensures secure handling of sensitive health data.
